## 舆情热度与传播

当前样本中，高考议题的高热内容主要出现在抖音，微博仅见一条互动样本；抖音高热内容集中于考场突发救助、考后采访与高考历史类题材，互动结构普遍表现为点赞、转发突出而评论量分化，微博样本则呈点赞占绝对多数的结构。不同平台指标口径不一致，以下仅作平台内描述，不作跨平台绝对数值比较。

抖音样本中，[证据 1]（抖音，https://www.douyin.com/video/7649010567218269474）“高考生进考场前下巴脱臼……民警找医生复位”点赞 1931951.0、转发 998751.0、评论 115.0；[证据 3]（抖音，https://www.douyin.com/video/7648573219535916303）关于“高考因为有他的坚持，才有了选择题”点赞 1985945.0、转发 377315.0、评论 133.0。两条均呈高点赞、高转发、极低评论。相较之下，[证据 2]（抖音，https://www.douyin.com/video/7648330461677491674）高考采访类点赞 1665364.0、评论 13428.0、转发 514342.0；[证据 5]（抖音，https://www.douyin.com/video/7648855598586531118）物理考后采访点赞 460782.0、评论 52641.0、转发 180357.0，评论参与明显更高。可见样本内高热内容的互动结构并不统一：突发救助与情怀类偏点赞/转发驱动，采访类评论参与更突出。部分内容收藏也较高，如[证据 3]收藏 85084.0、[证据 2]收藏 83726.0。评论区亦有高赞短评，如[证据 10]（抖音，https://www.douyin.com/video/7648443975250112424）点赞 114857.0、回复 753.0，但内容简短，不推断其具体指向。

微博样本仅见[证据 15]（微博，https://m.weibo.cn/detail/5307562970843517），点赞 36935.0、评论 520.0、转发 42.0、收藏 0.0，互动集中于点赞。由于微博样本仅1条，且缺少低热度基线与时间序列，无法判断微博端整体热度分布、演变趋势，也难以与抖音样本作跨平台比较；抖音样本的评论量分化原因亦无法从现有数据确认。

## 公众情感与观点

本次样本中，微博与抖音评论对高考的情绪以祝福鼓励为主，同时出现反思人生阶段、调侃重复表达和对讨论例行化的质疑；样本多为短评论，不能视为总体民意。

祝福鼓励重复度最高。微博多次出现“高考加油”“高考加油！金榜题名！”（[证据1][证据11][证据15]，weibo，https://m.weibo.cn/detail/5307822046970372）；抖音有“高考加油！”（[证据2]，douyin，https://www.douyin.com/video/7648573219535916303）、“高考必胜！”（[证据6]，douyin，https://www.douyin.com/video/7648148494380780840）、“高考加油吧祝孩子们取得好成绩”（[证据16]，douyin，https://www.douyin.com/video/7649010567218269474）和“为高考静音”（[证据18]，douyin，https://www.douyin.com/video/7648443975250112424，点赞 114857.0 / 回复 753.0）。这些是用户表达，样本内呈支持性情绪。

反思型观点强调高考后的成长：微博称“高考不是终点，而是人生新的起点！”（[证据4]，weibo，https://m.weibo.cn/detail/5307869622961764）；“高考结束，也是成年生活的正式开启……”（[证据8]，weibo，https://m.weibo.cn/detail/5307882226059057）；“更重要的是……真正思考，从‘我必须赢过别人’转向‘我到底要把自己带到哪里’”（[证据9]，同上，点赞 17.0）。另有微博讨论“高考政治这么难吗？”（[证据7]，weibo，https://m.weibo.cn/detail/5307883493524852，点赞 1.0 / 回复 4.0）。

抖音多条评论重复“大家有没有发现，凡是高考的，都是高三的孩子”（[证据12]，douyin，https://www.douyin.com/video/7649010567218269474，点赞 6763.0；[证据14]，douyin，https://www.douyin.com/video/7648541436875194495，点赞 11154.0 / 回复 1092.0；[证据19]，douyin，https://www.douyin.com/video/7648443975250112424，点赞 544.0 / 回复 26.0），属调侃式重复。短评论“怎么就这几个人高考呢[发呆]”（[证据10]，douyin，https://www.douyin.com/video/7648330461677491674）对象不明确，不推断其支持或反对。

分歧在于关注度评价：微博有评论认为“高考已经变成例行公事一样了，没什么好评论的，一个个案”（[证据20]，weibo，https://m.weibo.cn/detail/5307494492013476，点赞 34.0），与大量祝福和调侃形成对照。现有样本缺少覆盖面、语境和系统性调查，无法推断全网民意。

## 平台与群体差异

当前样本中，微博与抖音均出现“高考加油/必胜/金榜题名”类祝福；差异主要在于，微博样本另见考试难度、情绪调适、人生规划与高考价值反思等成段讨论，抖音样本则以短句祝福和口语化调侃/观察为主。样本有限，以下仅描述所给证据，不推断平台整体用户画像。

共同表达上，微博 [证据 1]（微博，https://m.weibo.cn/detail/5307822046970372）与抖音 [证据 3]（抖音，https://www.douyin.com/video/7648573219535916303）、[证据 20]（抖音，https://www.douyin.com/video/7649010567218269474）均为短祝福；[证据 20] 点赞 6709.0，[证据 3] 点赞 600.0。

微博样本议题更分散：[证据 4]（微博，https://m.weibo.cn/detail/5307903645849440）问“高考考场上紧张，该如何缓解情绪”；[证据 9]（微博，https://m.weibo.cn/detail/5307883493524852）说“高考政治这么难吗”；[证据 6]（微博，https://m.weibo.cn/detail/5307869622961764）、[证据 11]（微博，https://m.weibo.cn/detail/5307882226059057）转向“人生新的起点”与“真正思考”。[证据 14]（微博，https://m.weibo.cn/detail/5307882226059057）谈高考作为“分水岭”和葛军播客，点赞 220.0 / 评论 13.0 / 转发 61.0；[证据 16]（微博，https://m.weibo.cn/detail/5307845428908312）称高考重要性弱化、学历贬值，提及每年毕业 1200多万学生、985 211 等，点赞 287.0 / 评论 97.0 / 转发 3.0。可见微博样本对高考价值有不同侧重，证据不足以判断何者占多数。

抖音样本中，[证据 18]（抖音，https://www.douyin.com/video/7648541436875194495）“大家有没有发现，凡是高考的，都是高三的孩子”点赞 11154.0 / 回复 1092.0；[证据 15]（抖音，https://www.douyin.com/video/7649010567218269474）相近句式加“高考加油”，点赞 6763.0 / 回复 1.0；[证据 12]（抖音，https://www.douyin.com/video/7648330461677491674）“怎么就这几个人高考呢[发呆]”点赞 8.0 / 回复 1.0。所给抖音证据未出现微博样本中的学历贬值、考场情绪或人生转向的成段讨论。

综上，当前样本支持的差异是表达形态和议题范围：微博有更多长文、标签和反思性讨论，抖音更多短评、口语化调侃/观察；但两平台都含祝福短句，且样本量小，缺系统抽样和用户属性，无法据此推断群体差异。

## 深层原因与影响

当前样本可支持的核心发现是：微博、抖音用户对高考的讨论已从试题难度延伸到选拔功能、社会流动与分流后果；但这些主要是用户归因，缺少官方政策材料佐证。

归因上，[证据1]（微博，https://m.weibo.cn/detail/5307845428908312）称学历贬值、每年毕业1200多万学生、除985 211外文凭无区别，中产以上家庭可绕过高考，真正靠高考改变命运“可能就剩下农村或者城市底层，有读书天赋的孩子”。[证据3]（抖音，https://www.douyin.com/video/7648939065064115465）称高考“揭开了只筛选，不培养的大幕”，筛选“有灵性”学生深造，其他学生去专科成为技能型人才。[证据4]（抖音，https://www.douyin.com/video/7647396113951406762）称AI时代死记硬背失效，国家为高考改革大洗牌，选科研人才。[证据6]（抖音，https://www.douyin.com/video/7648599264814636403）把2010年数学理综难归因于国家需要数理化人才，称2026年“不光需要人才，更需要天才”。[证据2]（抖音，同证据4链接）强调高考是国家选人才，“关键难题绝大部分人不会就对了”。[证据7]（抖音，https://www.douyin.com/video/7648947265968639247）称题目出乎意料让“寒窗苦读十二年的孩子们心灰意冷”，老师也需更新。上述均为用户归因。

影响与风险上，样本担忧集中于考生情绪、学习方法、教师更新和分流焦虑。分析性推断：若“学历贬值”“只筛选不培养”“家庭资源决定”等叙事持续扩散，可能放大公平焦虑和对高考选拔正当性的争论。样本内部分歧明显：[证据1]倾向弱化高考决定作用，[证据2][证据3][证据4][证据6]仍强调国家选拔/筛选功能；难度体验上[证据5]（抖音，同证据3链接）称最后一题“难度不是很大，但是也不是特别简单（当然我会高中数学）”，与[证据6][证据7]的难度叙事不一致。缺失官方命题或改革说明、系统调查和更广样本，无法判断上述归因是否成立或代表整体。
