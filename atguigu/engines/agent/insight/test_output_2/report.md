# 关于高考难不难的舆情分析报告

## 报告摘要

现有样本显示，2026年6月7日至9日，微博和抖音围绕高考各科难度、高考意义与现场应援形成集中讨论；各科“难不难”的评价并不一致，且多为发布者或受访者表达，不能视为已核实的整体难度结论。抖音样本中难度话题形成高热，数学结束后的现场情绪类视频互动量突出，但高热不限于难度本身；难度评价在数学、物理、英语等科目及个体表达间存在分歧。公众情感与观点上，既有难度相对化、排名中心的观点，也有难题对特定层次考生影响不均的观点，二者存在冲突，样本无法判断何者更普遍。平台差异方面，抖音讨论更集中在具体科目难度及其对不同层次考生的影响，微博讨论更常延伸到高考意义、情绪与人生反思。深层讨论涉及选拔功能、时代变革、教学批判、社会流动弱化等归因，并牵出学历贬值与家庭资源分流对高考价值的重估；现有样本缺少各科官方难度数据、系统抽样评论、平台算法推荐信息、官方命题说明及主管部门回应等，难以推断全网热度或公众整体共识。

## 事件背景与概览

## 舆情热度与传播

本次样本中，高考难度话题在抖音形成高热，数学结束后的现场情绪类视频互动量突出；微博仅见一条样本，互动口径与抖音不同，不宜直接比较。抖音样本里，[证据1，抖音](https://www.douyin.com/video/7648599264814636403)称6月7日数学考后考生“面露愁容”，获点赞1787471.0、评论249946.0、转发984695.0、收藏62975.0，是难度相关样本中互动最高的一条。但同平台高互动还有[证据2，抖音](https://www.douyin.com/video/7649010567218269474)“下巴脱臼现场复位”（点赞1931951.0、评论115.0、转发998751.0、收藏53575.0）和[证据4，抖音](https://www.douyin.com/video/7648573219535916303)“选择题由来”（点赞1985945.0、评论133.0、转发377315.0、收藏85084.0），说明高热不限于难度本身。

难度评价存在分歧：数学方面，[证据5，抖音](https://www.douyin.com/video/7648590692948329893)数学采访点赞421849.0、评论15262.0、转发357154.0；[证据9，抖音](https://www.douyin.com/video/7647396113951406762)与[证据17，抖音](https://www.douyin.com/video/7648995544622255406)标题均指向数学大题或数学难。物理方面，[证据6，抖音](https://www.douyin.com/video/7648855598586531118)考生称“物理非常简单”，点赞460782.0、评论52641.0、转发180357.0；[证据11，抖音](https://www.douyin.com/video/7648860424963640619)考生则称“创新很多，比去年难多了”，点赞143781.0、评论7070.0、转发40927.0。英语方面，[证据14，抖音](https://www.douyin.com/video/7648993794553105674)人大附中考生表示“一般”，点赞46194.0、评论4226.0、转发13048.0。可见样本内对难度的科目感受和个体表达并不一致。

传播特征上，[证据7，抖音](https://www.douyin.com/video/7648939065064115465)数学学习方法类视频点赞154539.0、转发121395.0、收藏116478.0；[证据10，抖音](https://www.douyin.com/video/7648947265968639247)“怎么都说今年高考变难了”点赞43090.0、转发72494.0、收藏49603.0；转发或收藏相对突出，可能反映观点与工具性内容更易被转存，但这是基于互动结构的分析。微博样本[证据19](https://m.weibo.cn/detail/5307562970843517)仅一条，点赞36935.0、评论520.0、转发42.0、收藏0.0，内容为“高考学校门口挂零了，今天还要去吗”，未直接评价难度；因平台口径不同，不能与抖音绝对数值比较。另有抖音评论[证据20](https://www.douyin.com/video/7648541436875194495)获赞11154.0、回复1092.0，内容为调侃“凡是高考的都是高三孩子”，未明确指向难度，不据此判断其立场。现有证据缺少微博多条样本、系统抽样及算法推荐信息，难以推断全网热度。

## 公众情感与观点

本次样本中，“高考难不难”的讨论呈现两条主线：抖音评论多围绕难度、排名与考生分层展开，微博评论则更多出现鼓励、人生反思及对具体科目的疑问；对“难题是否改变不同层次考生的相对位置”存在明显分歧。以下仅为该样本观察，不能视为总体民意。

抖音短评有直接、调侃式回应，如“不难啊”[证据2，抖音](https://www.douyin.com/video/7648860424963640619)、“难么？”[证据4，抖音](https://www.douyin.com/video/7648995544622255406)、“出卷人出题不难体现不了他们水平”[证据3，抖音](https://www.douyin.com/video/7648977699520191205)。微博也有“大题难归难，选填难度其实不算大吧”[证据19，微博](https://m.weibo.cn/detail/5307611349516877)、“高考政治这么难吗？”[证据6，微博](https://m.weibo.cn/detail/5307883493524852)、“今年数学难吗？”[证据8，微博](https://m.weibo.cn/detail/5307611349516877)等个人感受或提问。

一种反复出现的观点是难度相对化、排名中心：有用户称“高考难不难和被狮子追是一个道理……全省排名才是关键”[证据1，抖音](https://www.douyin.com/video/7648995544622255406)；也有人认为“难的话大家不都一样难”“卷子简单才完蛋”[证据17，抖音](https://www.douyin.com/video/7648599264814636403)，“数学难与不难，对学霸与学渣来说都是一样的”[证据14，抖音](https://www.douyin.com/video/7648590692948329893)，“高考是国家选人才……关键难题绝大部分人不会就对了”[证据20，抖音](https://www.douyin.com/video/7647396113951406762)。

另一种观点则强调难题对特定层次考生影响不均：有评论称数学难时“数学更好的同学……天塌了”[证据9，抖音](https://www.douyin.com/video/7648599264814636403)，或认为出题难“有利两类人”即顶尖与末尾[证据10，抖音](https://www.douyin.com/video/7648590692948329893)，中等偏上学生受损，并借22年经历称“如何释怀”[证据12，抖音](https://www.douyin.com/video/7648599264814636403)；另有用户称其子平时120+、高考98，同桌59，“当场崩溃哭了”[证据15，抖音](https://www.douyin.com/video/7647396113951406762)。这与“对学霸学渣都一样”的表述形成冲突，样本无法判断何者更普遍。还有评论质疑“学霸说不难”的可参考性：“他们说英语不难，没有参考性……但英语我信他们肯定有水平”[证据7，抖音](https://www.douyin.com/video/7648993794553105674)。

微博评论还出现将高考置于人生历程的表达：“高考不是终点，而是人生新的起点”[证据5，微博](https://m.weibo.cn/detail/5307869622961764)；“高考结束，也是成年生活的正式开启……”[证据11，微博](https://m.weibo.cn/detail/5307882226059057)；“更重要的是……从‘我必须赢过别人’转向‘我到底要把自己带到哪里’”[证据13，微博](https://m.weibo.cn/detail/5307882226059057)；“高考加油！金榜题名！”[证据18，微博](https://m.weibo.cn/detail/5307822046970372)。

样本局限明显：以抖音、微博评论为主，互动数据多数为0或个位数，且无抽样说明；缺少各科难度的系统评价和评论总体分布，不能据此推断公众整体情绪。

## 平台与群体差异

本批样本显示：抖音讨论更集中在具体科目难度及其对不同层次考生的影响，表达短促、比喻化；微博讨论更常延伸到高考意义、情绪与人生反思。两平台样本均有限，不能据此推断平台整体用户画像。

抖音样本中，高互动作品多以数学、英语“难不难”为入口。[证据 16]（抖音，https://www.douyin.com/video/7648939065064115465）文案称高考数学题是给小学初中家长的“善意提醒”，并称“高中生家长还在争论题目难不难”，点赞154539.0、评论12902.0、转发121395.0；[证据 18]（抖音，https://www.douyin.com/video/7648993794553105674）以“人大附中考生表示一般”报道英语难度，点赞46194.0、评论4226.0、转发13048.0。评论更偏竞争逻辑：[证据 1]（抖音，https://www.douyin.com/video/7648995544622255406）用“被狮子追”比喻，称“全省排名才是关键”；[证据 14]（抖音，https://www.douyin.com/video/7648599264814636403）长评称题难主要打击“中等偏上但又不是顶尖的学生”，而“平时啥也不会的学生也能考50”。这些均为用户表达或个体判断，不是已证实事实。

微博样本中，直接问科目难度的有[证据 8]（微博，https://m.weibo.cn/detail/5307883493524852），称“高考政治这么难吗”，并自称“28年高考物化政考生”；该条点赞1.0、回复4.0。更多微博文本转向意义与心态，[证据 19]（微博，https://m.weibo.cn/detail/5307882226059057）将高考视为“强力系统变量”并提及葛军播客，点赞220.0、评论13.0、转发61.0。

冲突在于：抖音[证据 1]强调排名使难易“无关紧要”，[证据 14]则强调题难会实际改变中等偏上考生的录取处境；本批微博样本未形成对应系统争论。缺失两平台代表性抽样、评论对象上下文及用户身份/地区分布，无法进一步比较群体构成。

## 深层原因与影响

当前微博、抖音样本支持的核心发现是：对“高考难不难”的讨论已从题目难度转向选拔逻辑、技术变革与教育方法之争，并牵出学历贬值与家庭资源分流对高考价值的重估。

成因上，用户归因主要有四类。一是选拔功能论，抖音评论称“高考是国家选人才，不是社会培训的结业考试，关键难题绝大部分人不会就对了”[证据3]（抖音，https://www.douyin.com/video/7647396113951406762）。二是时代变革论，有评论称“现在是AI时代了，以前的高考模式淘汰了，靠死记硬背套路没用了”[证据5]（抖音，同证据3链接），并称高考揭开“只筛选，不培养的大幕”[证据6]（抖音，https://www.douyin.com/video/7648939065064115465）。三是教学批判论，有评论称“不是题变难，是‘死刷题’时代结束；基础为王、思维致胜”[证据11]（抖音，https://www.douyin.com/video/7648947265968639247），也有人称“90%的老师水平都很低”、靠题海战术[证据10]（抖音，同证据6链接）。四是社会流动弱化论，微博用户称学历大幅贬值，每年毕业1200多万学生，除985 211外文凭在用人单位眼里没区别，中产以上家庭可绕过高考[证据1]（微博，https://m.weibo.cn/detail/5307845428908312）。以上均属用户表达，不是已证实事实。

影响与风险方面，样本中可见考生情绪与家长行动预期。抖音视频标题称杭高考生离场露愁容、女生差点哭[证据4]（抖音，https://www.douyin.com/video/7648599264814636403）；有评论称“越难越好……完全不顾后面学子的死活”，获点赞181.0[证据8]（抖音，https://www.douyin.com/video/7648590692948329893）。难度感知也存在分歧：微博评论认为“大题难归难，选填难度其实不算大吧”[证据2]（微博，https://m.weibo.cn/detail/5307611349516877）；初三学生则称最后一题“难度不是很大，但是也不是特别简单”[证据9]（抖音，同证据6链接）。基于这些样本可推断，后续舆情风险可能集中于选拔公平、分流焦虑、教师责任归因与考生心理；但现有证据仅为少量微博、抖音样本，缺少官方命题说明、主管部门回应及更广平台数据，无法判断整体公众态度或政策效果。
